# My AI

> I make an AI by myself, no TRANSFORMER, no RNN, no GNN, no GPU.

这是一个从零实现的**生长型脉冲神经网络**。不依赖任何主流框架，不靠反向传播，没有矩阵乘法，纯C++。

## 🧠 它是什么？

**它不是Transformer，不是RNN，不是GNN。**

它是我自己定义的一种神经网络架构——

- 神经元在训练中**动态生长**
- 连接根据共现关系**自动建立、增强或衰减**
- 信号通过**脉冲激活**在图中传播
- 内存占用会自然增长到**稳态平衡**

通俗地说：它更像一个“会学习的生物脑”，而不是一个“堆参数的大模型”。

## 🚀 怎么跑？

1. 下载本仓库
2. 准备 `train.txt`（**必须**）/ `knowledge.txt`（**可选**），编码格式为 **UTF-8 without BOM**
3. 双击 `未命名23.exe`（Windows）

## 📊 它现在能做什么？

项目已经迭代了两个可验证的版本，能力如下：

| 版本 | 数据量 | 训练轮数 | 学会什么 |
|------|--------|----------|----------|
| v1   | 66 KB  | 1        | 能说出**词语** |
| v1   | 500 KB | 1        | 能说出**概念关联**的文本 |
| v1.5 | 500 KB | 1        | 能说出**结构化短句**（如“数学易造成”） |

是的，目前还不会完整的语法，但它正在从“词”走向“句”。

## 🎯 为什么要做这个？

因为我觉得：

> **“AI不应该只有一种写法。”**

Transformer很强大，但我想试试——**不用它，能不能造出一个能学习的AI？**

目前答案是：**能。**

虽然它还很弱小，但它已经学会了一些东西。而且它是我自己和LLM一起写的，每一个神经元都是。

## 📌 当前局限

- 目前仅支持 Windows
- 大语料下内存占用较高（16GB 能跑也只能跑 500KB 数据）
- 语法能力还很浅，只能生成短句

## 🔭 未来的方向
